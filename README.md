# Clase 17 — Práctica de Git

Proyecto educativo para demostrar el flujo de trabajo de Git con commits, ramas, Pull Requests, merge y reversión de cambios.

## Aplicación

Se desarrollará una lista de tareas sencilla utilizando HTML, CSS y JavaScript sin dependencias. Abrí `index.html` en tu navegador.

## Temas

- Directorio de trabajo, staging area y repositorio local.
- Commits y seguimiento de versiones.
- Ramas `main`, `develop` y `feature/*`.
- Colaboración con Pull Requests y merge.
- Reversión de cambios en una rama de práctica.

El historial de GitHub y los Pull Requests son la evidencia real de los ejercicios.
